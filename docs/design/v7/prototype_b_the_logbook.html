§howit works

How it works, in four sentences

  1. His scale, sleep band, mattress, gym app and food log send their numbers every day to a store he built and runs himself.
  2. Plain code — not AI — computes every figure on this page from those records, and prints the day and the count beside it; where it can't vouch for a number, it prints the refusal instead.
  3. Eight AI coaches read those figures each morning and write down what they expect next; code grades those calls later against what actually happened, and no coach writes its own verdict.
  4. The misses stay on the record next to the hits. Running all of it has cost $102.74 so far this month, for one subscriber.
