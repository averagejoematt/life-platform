How it’s built

What runs, what it costs, and what has broken.

One person’s health data, read by AI coaches whose predictions are graded by code. Matthew is not an engineer. He decided what the system does and set its limits. The code was written with an AI assistant, Claude.

What runs

One picture.

A change goes live when the automated checks pass. Only a change to what the programs are permitted to do waits for Matthew.

The numbers

Counted, with dates.

This is more machinery than one person’s data needs. That is deliberate: it is a working tool and also a public demonstration of engineering practice.

Cost

A ceiling, and what switches off.

A program forecasts the month-end bill every 8 hours and sets a tier.

  • Tier 1From about 73% of the ceiling. Behind-the-scenes AI stops. Nothing a reader sees changes.
  • Tier 2From about 87%. The coaches’ daily commentary and the weekly writing and podcast stop.
  • Tier 3From about 97%. All AI stops. A reader’s question gets a “paused” answer.

Who decides

What a person approves, and what he does not.

  • LimitsThe monthly ceiling and the order of the pauses were decided in advance and written into code.
  • ApprovalMatthew approves one thing by hand: a change to what the programs are permitted to do. Everything else, program code and pages alike, goes live when the automated checks pass, with no manual approval step. A repair agent runs three times a week. It can propose a fix and cannot apply one.
  • ControlsTests run on every change. After an update a script opens the pages in a browser, and a failed check undoes the update. Alarms watch what runs.
  • In publicEvery graded prediction is published, right or wrong. The code and the incident log are public.

What broke

Failures, newest first.

  • Oct 4
    The coaches’ new daily lines passed their tests, went live and showed none.

    What happened: on its first real run the AI chose three coaches to speak and the code refused all three. Impact: the preview front page said no coach had anything to say that day. Cause: the AI named each coach, and the code only recognised a short code for each. How it was found: a person read the first live output. No monitor flagged it. What changed: the code accepts a name, and that output is now a test case. The fix

  • Sept 1
    The public ask-the-coaches feature returned errors for about 34 hours, across launch day.

    A quality check was given a 10-second limit, taken from a code comment that said it needed 2 to 5 seconds. Measured, its typical run was over 10. A monitor caught the failure the first morning. Nobody read that alarm for about 31 hours. Changed: the check was removed from the reader’s path. The incident log

  • Aug 26
    A feature passed its tests, was closed as done, and had never worked.

    It was meant to tell a harmless failed check from a real one. One lookup came back with the needed line missing, and the feature quietly did nothing. Found within the hour by using it on real work, not by an alarm. Changed: fixed the same day, and accepted only on a live result. The incident log

  • Aug 11
    The AI judge that blocks bad coach text passed invented numbers.

    Three test texts with made-up figures scored 92, 92 and 82 out of 100 and passed. The judge’s instructions had no rule about invented numbers. A separate check written in code did catch them, and none is known to have reached a reader. Found the first time the judge was measured against examples with known answers. Changed: the blocking step now uses the code check’s verdict. The incident log

In his words

What I decided, and what I can’t verify myself.

Draft wording. Matthew has not rewritten this yet.

I decided what gets measured, what the goal is, and that the coaches would be graded by code against a simple guess and the result printed when they lose. I set the monthly ceiling and chose what pauses first.

I did not write the code and I cannot tell by reading a change whether it is correct. The one thing I approve by hand is a change to what the programs are permitted to do. Everything else goes live when the automated checks pass. I see the result, not every line.

What I can check myself is whether a number about my own day is true. For the rest I rely on the tests, the alarms and the published record of misses.
