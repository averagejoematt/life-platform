# the returned Content.Location zip's *.dist-info). pillow-layer:1 actually ships
# pillow-11.3.0.dist-info — NOT 11.2.1 as this file previously pinned. The old pin
# was a pre-#1336 conservative estimate that was never checked against the real
# artifact. This pin is now ground truth (the #1336 OWNER ACTION this comment used
# to ask for), not an estimate.
#
# NOTE (dependency-bump triage, #1778): Dependabot proposed bumping this pin to
# 12.3.0. That edit alone would NOT change what's deployed — the layer is built
# offline and this file has no install step wired to it (checked deploy/build_bundle.py
# and deploy/deploy_lambda.sh: neither pip-installs from any lambdas/requirements/*.txt;
# third-party code only reaches a running Lambda via these binary layers). Taking a
# real Pillow upgrade requires rebuilding pillow-layer offline (linux/x86_64 wheels),
# publishing a new layer version, and bumping PILLOW_LAYER_VERSION in
# cdk/stacks/constants.py — no build script for this exists in deploy/ today. See the
# #1778 close comment for the full writeup.
