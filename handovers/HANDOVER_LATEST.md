## Gotchas learned
- **`cdk diff` writes the diff to stderr** — `2>&1 > file` captures nothing; use `> file 2>&1`.
- **The IAM PR gate reads labels at trigger time** — add `owner-required-ack` BEFORE the push, or remove/re-add it to fire the `labeled` run.
- **A `put-bucket-policy` from either twin document drops the other half** — the reconcile smoke's own "Fix:" line was the apply that kept the trail dark. One document now; the test bans the inline literal.
- **The wrap's `main-green` reads the newest COMPLETED run** — a stranded run followed by an in-progress rerun still reads stranded until the rerun completes; the Plan rerun needs the owner deploy to have landed first (it did: Plan green on retry).
