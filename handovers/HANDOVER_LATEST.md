## Gotchas learned
- **`git bundle create` needs a ref name** — a bare sha fails silently in a loop; tag a detached head first and keep the filename flat (a `/` in the tag name writes into a missing subdirectory).
- **A handover's "archived at <path>" must be `ls`-verified** — the Session CO claim named a directory that did not exist until this session created it; the dirty diffs were archived here instead.
- **Past drivers never released lane locks** — 36 `LOCKED (lane in use)` lanes from weeks-old sessions; `/land` §5 is the rule, this session is the catch-up. After an integration-lane squash the lane PR reads CLOSED and the reaper cannot prove it; grep main's squash messages for each commit subject.
- **Run the green assertion and `gh pr merge` as separate commands** — the watcher hook flags the chained form (it has twice merged past an unread verdict).
- **A Monitor loop must exit on its event** — one that prints the event every iteration floods the channel; `.conclusion // "pending"` reads an empty string as settled, use `.status`.
- **`cdk diff` hides a tag-only change** behind the metadata filter — "no differences" is not "nothing to ship"; the Plan step sees it.
- **`gh pr merge --delete-branch` fails on a locked lane** — release the lane first (the merge itself succeeds).
