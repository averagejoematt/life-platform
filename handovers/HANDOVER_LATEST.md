## Gotchas
- **A verifier "ship" is not a gate read — 5 of 15 ship-verdict PRs went red in CI, every time on a PAIR:** #4873's live captures lacked the `absent` key #4872 had just added; #4876's craft review matched the stats-honesty test's `*grades*.json` glob and became "the newest review"; #4870's loader put a `fromisoformat` outside the ISO registry; #4899 grew `check_github_config` past the record #4902's new ratchet pinned in the same train (the train's stacked gate caught it before any merge — the fix is the ratchet's own remedy, two extracted helpers, never a raised number); #4873 again on the built page's height after the recapture. The rule held: `gh pr update-branch` after every merge touching a shared file, read the gate, bare squash.
- **Watchers must print the verdict line.** One merge (#4897) went in on a `tail -3` that cut `ALL GREEN`; the checks were green, the read was blind. Grep `ALL GREEN|NOT GREEN|VERDICT`; a strict watcher exits only on green or a real FAILURE state, never on the word "failed" in prose.
- **`gh pr update-branch` can say "conflicts" and still leave a merge commit on the branch** (#4871) — a lane resolving the conflict must `git fetch` first or its push is rejected.
- **Filing from a review follows the issue-filer contract:** Later is a `## Backlog rows` line, ≤10 stories per batch, and a review-filed story needs a `## Set` section or nightly hygiene reds (3 of 7 did).
- **Comment timestamps come from `date -u` / `mergedAt`, never a mental clock** — four comments were patched after a one-hour drift.
- **The reader-truth judge is nondeterministic across runs on unchanged content** (3 HIGHs per run, different pages each time); a sentence-matched ruling buys one run. Structural rulings (the page's quoted copy, window arithmetic) are the only durable fix short of re-dating EP4.
- A paired lane edit to the same test file (`test_platform_stats_honesty_3690.py` in #4871's marker sweep and #4876's selector fix) is invisible to each PR's own gate — the overlap check `comm -12 <(gh pr diff N --name-only) <(git diff --name-only <base> origin/main)` before each merge is what caught it.
